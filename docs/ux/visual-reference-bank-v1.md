# Bússola — banco de referências visuais V1

Status: working reference bank  
Purpose: support art direction for the public Bússola case without copying layouts, brand assets or interaction patterns wholesale.

## How to use this bank

This is not a moodboard to imitate. Each reference is tagged by the **specific design problem it solves**.

For every visual route, extract:
- what creates the first-impact moment;
- how image and copy share the hero;
- how product/UI evidence enters the composition;
- how section rhythm changes through the page;
- how dense information remains legible;
- what creates authorship beyond generic SaaS patterns.

Avoid importing:
- brand palettes;
- proprietary illustrations;
- logos;
- signature motion;
- distinctive compositions one-to-one.

## Reference lanes

### A. Hero with character + strong visual field

#### ShiftKey — Demo 1
https://shiftkey-nextjs.vercel.app/demo-1

**Why it matters**
- split hero with headline/copy on one side and a character scene on the other;
- supporting floating elements create depth and make the hero feel designed rather than merely formatted;
- high-contrast background establishes a visual world immediately;
- imagery is not subordinate to the copy.

**For Bússola**
Use the composition logic for Fernando:
- Fernando as a large protagonist, not a small illustrative card;
- surrounding evidence can include fragments of UI, financial signals, goal/apartment references or documented system cues;
- supporting elements must carry meaning, not decorative tech iconography.

**Do not copy**
Purple/blue gradient, generic SaaS CTA system, floating coding icons, wave dividers.

## Initial synthesis for Bússola

The strongest route is not "editorial instead of SaaS". It is:

**human protagonist + financial evidence + product craft + technical depth**

Hero:
- Fernando large enough to own the first fold;
- title and narrative remain simple;
- supporting visual evidence creates depth;
- one strong visual field, not a stack of cards.

Discovery:
- use a real-looking but clearly synthetic/data-study visual language;
- make "saldo positivo" versus "uso do rotativo" visually graspable;
- no invented transactions or confidential percentages.

Architecture:
- treat documented architecture as a visual artifact;
- use hierarchy, annotations and selected evidence;
- avoid decorating a made-up diagram.

UX evolution:
- screens large enough to read;
- before/after as a hero section of craft;
- one decision per pair;
- preserve historical contrast failures where they are evidence.

Team:
- use portraits with enough scale to feel human;
- documentary/event photography can add energy if rights/provenance are clear;
- avoid corporate directory treatment.

## Reference scoring rubric

Score each new reference 0–2 on:
- **Distinctiveness** — would we remember the page after closing it?
- **Narrative fit** — does the visual help tell a story, not just sell?
- **Evidence fit** — can real artifacts participate in the layout?
- **Product clarity** — does visual personality preserve comprehension?
- **Responsive plausibility** — can the idea survive 390px?
- **Accessibility plausibility** — can contrast, reading order and interaction remain robust?

Keep references scoring at least 8/12.  
A visually impressive reference that cannot support readable product evidence should not drive Bússola.
