**Source:** `docs/ux/visual-reference-bank-v1.md` plus recorded ShiftKey analysis  
**Important limitation:** this run synthesizes the repository’s already-curated reference notes. It does not claim a fresh live audit of every external site/interaction.

## 1. What the references collectively say

The strongest common lesson is **not** “make it editorial” and not “make it fintech”.

It is:

> **Build one authored visual world in which people, evidence and product artifacts participate in the same composition.**

The references are useful when they help Bússola solve one of six concrete problems:

1. give Fernando real protagonist scale;
2. make financial/data evidence visually graspable without inventing data;
3. show product craft at readable scale;
4. make technical architecture visually valuable rather than footnoted;
5. vary pacing across a long case without falling into card grids;
6. keep the idea strong at 390px.

## 3. High-confidence compositional principles

### P1 — Person + product = one scene

Fernando should not sit beside a screenshot as two independent columns.

**Extracted principle:** person and UI share depth, crop, alignment or overlap so they are read as one visual argument.

**Guard:** the relationship must still make sense with motion disabled.

### P2 — One dominant idea per visual moment

The previous hero tried to carry headline, Fernando, UI, financial insight, provenance and supporting bars simultaneously.

**Extracted principle:** each high-impact section needs a single dominant visual idea; secondary evidence moves downstream.

For hero, the strongest candidate remains **Fernando + one product state**.

### P3 — Evidence is visual material

The case already has:
- synthetic-data analysis;
- architecture docs;
- UI states;
- commit/history evidence;
- team portraits;
- prototype.

These should be treated as source material for composition, not compressed into decorative cards.

### P4 — Scale changes create pacing

A long page should not repeat “heading + paragraph + 3 equal items”.

Possible rhythm:
- human-scale hero;
- denser data/evidence spread;
- intimate Fernando/context moment;
- wide technical artifact;
- large craft comparison;
- immersive prototype;
- documentary team;
- concise colophon.

This sequence is a pacing hypothesis for Art Direction, not a fixed layout.

### P5 — Product screens must be readable enough to count as evidence

The UX section fails when device chrome and neutral whitespace dominate the actual decision being compared.

**Rule:** prioritize the state/change, not the mock-device frame.

### P6 — Mobile is recomposition

390px is not a shrink/stack target.

The narrow layout may:
- crop a person or UI intentionally;
- change overlap;
- change scale;
- alter reading order;
- reduce nonessential layers.

It may not turn an authored desktop relationship into five sequential boxes.

### P7 — Restrained palette, authored composition

The references do not justify a campaign color system.

A limited palette can work if:
- scale;
- crop;
- type-image relation;
- material evidence;
- whitespace tension;
- contrast between section densities

are doing the authorship.

### P8 — Motion is a finishing layer

The reference bank contains motion-rich work, but motion is not transferable by default.

Use only when it explains:
- transition;
- spatial relation;
- state change;
- narrative sequence.

No loop or parallax is required for the case to feel authored.

## 4. Section-level implications

### Hero

**Problem:** prior attempts oscillated between generic editorial layout and too many floating layers.

**Direction principle:** one dominant human/product scene; headline remains independent and strong; provenance is subordinate.

### Discovery

**Problem:** qualitative data insight is correct but visually academic.

**Direction principle:** represent the tension “saldo positivo ↔ uso do rotativo” as an evidence relationship/ledger/analysis artifact, without inventing transactions or percentages.

### Fernando

**Problem:** risk of repeating the hero.

**Direction principle:** use a different crop/scale or a different associated artifact. The section should deepen context, not replay the opening.

### Architecture/process

**Problem:** technical depth currently reads like a list.

**Direction principle:** elevate the documented architecture itself as a major artifact with selective annotation and source.

### UX evolution

**Problem:** current page reads like documentation/design-system audit.

**Direction principle:** make each before/after pair a large craft spread with one decision to notice. Reduce device-frame dominance.

### Prototype

**Problem:** embedded product can look like another generic section.

**Direction principle:** treat it as a laboratory/demo moment with explicit PoC limits, not as a sales CTA.

### Team

**Problem:** previous result looked institutional.

**Direction principle:** documentary composition, human scale, visible contributions; avoid leadership-directory grammar.

### Closing

**Problem:** generic dual-CTA endings.

**Direction principle:** colophon: what was built, what changed later, what remains hypothesis, and where evidence lives.

## 5. Anti-pattern matrix

Reject a route when it depends on any of these as its main visual idea:

- full-wall color chosen only to “add impact”;
- multiple floating cards to simulate depth;
- serif + warm white as shorthand for editorial;
- repeated rounded containers;
- bento/card grids;
- small phone mockups inside large neutral panels;
- team headshot directory;
- stock “AI” motifs;
- animation required to make composition feel complete;
- desktop composition simply stacked for mobile.

## 6. What is still missing from the bank

The current bank is strong enough to begin Art Direction, but later research may add value in two narrow gaps:

1. **financial/data editorial** where qualitative relationships are visualized without overstating evidence;
2. **mobile case-study compositions** where person + product remain one scene at 390px.

Do not broaden research merely to collect more inspiration. Add references only if one of those concrete gaps blocks the Art Director.

## 7. Handoff to Art Direction

Use this synthesis as a constraint system, not a layout recipe.

The route should be testable against four questions:

1. Can the whole case be remembered by one visual idea?
2. Do real artifacts carry the visual system?
3. Does the mobile version preserve authored relationships?
4. Could the static page still feel complete with all motion disabled?

If the answer to any is no, return to composition before production.
